# CLAUDE.md

Guidance for Claude Code working in this repository.

## Before you commit — mandatory

**Read `AGENTS.md` first.** Every commit must be authored *and* committed as:

```
sata04 <88605918+sata04@users.noreply.github.com>
```

Verify with `git var GIT_AUTHOR_IDENT` and `git var GIT_COMMITTER_IDENT` — not
`git config`, which does not reflect `-c` overrides or `GIT_AUTHOR_*`
environment variables. **Stop before committing if either disagrees.**

Never use a project name (`AAT Web`, `AAT`) as a committer, never invent an
email, never pass `-c user.email=...`, never set `GIT_*` identity variables, and
never use `--no-verify`. This repository's first 37 commits had to be rewritten
because an agent did exactly that.

## What this project is

AAT Web is a local-first browser rewrite of AAT (Acceleration Analysis Tool), a
Python/PySide6 desktop application that analyses microgravity drop-tower
acceleration data from two sensors, Inner Capsule and Drag Shield.

The governing principle: **local analysis is the product; the cloud is an
optional authenticated research workspace.** A logged-out user with no network
must still be able to load a CSV, analyse it, inspect the graph, select a range,
read statistics, compare datasets and export Excel. See
`docs/web-architecture.md`.

## Compatibility contracts — do not casually change

- **`packages/analysis-core/src/numeric.ts`** reimplements NumPy's pairwise
  summation (block 128, eight-way unrolled partials, split rounded down to a
  multiple of 8). This is what makes the port bit-exact rather than
  approximately correct. Neighbouring analysis windows differ by less than any
  reasonable tolerance, so an approximate port would select a *different* window
  and report different science. See `docs/numerical-compatibility.md`.
- **`tests/golden/**`** is generated by the vendored Python reference.
  Regenerate with `python reference/python/generate_golden.py`; never hand-edit.
- **The poster style** (`poster-renderer/src/poster_renderer/preset.py`,
  `packages/plot-spec/src/presets.ts`) is frozen to the desktop export. Changing
  a colour, width or offset changes every published figure. Renovate is
  configured never to auto-merge anything under `poster-renderer/`.
- **`reference/python/core/**`** is a verbatim copy of the desktop application.

## Known deliberate difference from the desktop app

The desktop guard of 20,000,000 unified samples is a *memory* guard, unrelated
to the XLSX worksheet capacity of 1,048,576 rows. AAT Web enforces the real
limit and fails with `EXPORT_TOO_LARGE`, offering CSV, rather than building a
workbook it cannot write. This is a correction, not a regression.
